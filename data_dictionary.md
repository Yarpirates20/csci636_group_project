| Feature / metric code | Description |
| --- | --- |
| Active addresses — AdrActCnt | Number of unique active Bitcoin addresses each day. Approximation of network participation, not unique users. | 
| Transaction count — TxCnt	| Number of daily on-chain transactions. Measures network activity. |
| Hash rate — HashRate | Estimated computational power used to mine Bitcoin. May reflect mining activity and longer-term network conditions. |
| Transaction fees — FeeTotNtv |	Total daily transaction fees paid in BTC. May reflect network congestion and demand for block space. |
| Market value to realized value — CapMVRVCur |	Ratio between Bitcoin’s market capitalization and realized capitalization. Indicates aggregate holder profitability and valuation; incorporates price information. |
